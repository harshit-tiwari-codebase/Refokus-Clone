# Refokus-Inspired Interactive Web Experience

This project is a modern, animation-focused web application built using React, Tailwind CSS, and Framer Motion. It takes inspiration from high-end agency websites like Refokus and focuses on delivering smooth interactions, scroll-based animations, and a polished user experience.

## Features

* Custom loader with progress animation
* Scroll-based image reveal in the Work section
* Hover-based video preview in the Products section
* Infinite marquee animation without visible gaps
* Clean dark UI with responsive layout

---

## Tech Stack

* React (Vite)
* Tailwind CSS
* Framer Motion
* Optional: GSAP (for advanced animations)

## Installation

Clone the repository:

```
git clone https://github.com/your-username/your-repo-name.git
```

Move into the project directory:

```
cd your-repo-name
```

Install dependencies:

```
npm install
```

Run the development server:

```
npm run dev
```

---

## Build

To create a production build:

```
npm run build
```
